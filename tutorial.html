Lesson 1

Hello World — Your First Yeet

In Random++, you don't print things — you yeet them into existence. Let's start with the most important program ever written.

The yeet Statement

yeet is how you output text to the screen. It replaces print from other languages. You can yeet strings, numbers, variables — basically anything.

hello.rpp ▶ Try it 
# Your very first Random++ program!
yeet("Hello, World!")
yeet("Welcome to Random++!")
yeet("Let's get chaotic.")
Output
Hello, World! Welcome to Random++! Let's get chaotic.
Tip: Lines starting with # are comments — they're ignored by the compiler. Use them to explain your code (or leave snarky notes).

Lesson 2

Variables — Storing Your Stuff

Variables hold data — numbers, text, booleans, you name it. Random++ has unique keywords for boolean values that keep things real.

Booleans & None in Random++

nocap = True (no cap, it's really true)
cap = False (that's cap, it's a lie)
ghost = None (it ghosted you — nothing there)

variables.rpp ▶ Try it 
# Variables are created by assignment
name = "Random++"
version = 1.0
is_awesome = nocap
is_boring = cap
secret = ghost

yeet(f"Language: {name}")
yeet(f"Version: {version}")
yeet(f"Awesome? {is_awesome}")
yeet(f"Boring? {is_boring}")
yeet(f"Secret: {secret}")

# f-strings let you embed variables in text!
age = 1
yeet(f"{name} is {age} year(s) old and it's {is_awesome} that it slaps")
Output
Language: Random++ Version: 1 Awesome? True Boring? False Secret: None Random++ is 1 year(s) old and it's True that it slaps
Tip: Use f"..." strings (f-strings) to embed variables directly in text with {curly_braces}. Way cleaner than concatenation!

Lesson 3

Decisions — Bruh, Sus, or Nah?

Every program needs to make decisions. In Random++, you use bruh (if), sus (elif), and nah (else).

How decisions work

bruh checks a condition. If it's true, the indented code runs.
sus checks another condition if the first was false.
nah runs if nothing else matched.

Boolean operators: also = and, unless = or, nope = not

decisions.rpp ▶ Try it 
# Grade checker
score = 85

bruh score >= 90:
    yeet("A - Absolute legend!")
sus score >= 80:
    yeet("B - Pretty solid!")
sus score >= 70:
    yeet("C - You passed... barely")
nah:
    yeet("F - That's cap, try again")

# Boolean operators
age = 20
has_id = nocap

bruh age >= 18 also has_id:
    yeet("You're in!")
nah:
    yeet("Nah fam, can't let you in")
Output
B - Pretty solid! You're in!
Important: Indentation matters! Random++ uses 4 spaces to define code blocks (just like its inspiration). Don't mix tabs and spaces.

Lesson 4

Loops — Vibe Thru & Grind

Need to repeat something? Use vibe...thru for for-loops and grind for while-loops. bail to break out, skip to continue.

Loop keywords

vibe x thru collection: — iterate over items (for loop)
grind condition: — keep going while true (while loop)
bail — break out of the loop
skip — skip to next iteration

loops.rpp ▶ Try it 
# Vibe thru a range
yeet("Counting to 5:")
vibe i thru range(1, 6):
    yeet(f"  {i}")

# Vibe thru a list
fruits = ["apple", "banana", "cherry"]
vibe fruit thru fruits:
    yeet(f"I like {fruit}!")

# Skip even numbers, bail at 7
yeet("Odd numbers until 7:")
vibe n thru range(1, 20):
    bruh n == 7:
        bail
    bruh n % 2 == 0:
        skip
    yeet(f"  {n}")

# Grind (while loop) - countdown
yeet("Countdown:")
count = 5
grind count > 0:
    yeet(f"  {count}...")
    count -= 1
yeet("Liftoff!")
Output
Counting to 5: 1 2 3 4 5 I like apple! I like banana! I like cherry! Odd numbers until 7: 1 3 5 Countdown: 5... 4... 3... 2... 1... Liftoff!

Lesson 5

Functions — Cook & Serve

Functions are reusable blocks of code. In Random++, you cook them up and serve the result.

Function keywords

cook = def (define a function)
serve = return (send back a result)
quickmaf = lambda (one-liner function)

functions.rpp ▶ Try it 
# Cook up a greeting function
cook greet(name):
    serve f"Yo {name}, welcome to Random++!"

yeet(greet("Alice"))
yeet(greet("Bob"))

# Default parameters
cook power(base, exp=2):
    serve base ** exp

yeet(f"3^2 = {power(3)}")
yeet(f"2^10 = {power(2, 10)}")

# Recursion works too!
cook factorial(n):
    bruh n <= 1:
        serve 1
    serve n * factorial(n - 1)

yeet(f"5! = {factorial(5)}")
yeet(f"10! = {factorial(10)}")

# Quickmaf (lambda) - one-liner functions
double = quickmaf x: x * 2
yeet(f"Double 21 = {double(21)}")
Output
Yo Alice, welcome to Random++! Yo Bob, welcome to Random++! 3^2 = 9 2^10 = 1024 5! = 120 10! = 3628800 Double 21 = 42

Lesson 6

Lists & Comprehensions

Lists store ordered collections. Random++ supports all the list methods you'd expect, plus list comprehensions with vibe...thru syntax.

lists.rpp ▶ Try it 
# Basic list operations
heroes = ["Batman", "Spider-Man", "Deadpool"]
heroes.append("Iron Man")
yeet(f"Heroes: {heroes}")
yeet(f"Count: {len(heroes)}")
yeet(f"First: {heroes[0]}")
yeet(f"Last: {heroes[-1]}")

# List comprehensions - one-liner magic!
squares = [x ** 2 vibe x thru range(1, 6)]
yeet(f"Squares: {squares}")

# With a filter condition
evens = [x vibe x thru range(1, 11) bruh x % 2 == 0]
yeet(f"Evens: {evens}")

# Sorting
numbers = [42, 17, 99, 3, 56]
yeet(f"Sorted: {sorted(numbers)}")
yeet(f"Sum: {sum(numbers)}")
yeet(f"Max: {max(numbers)}")
Output
Heroes: ['Batman', 'Spider-Man', 'Deadpool', 'Iron Man'] Count: 4 First: Batman Last: Iron Man Squares: [1, 4, 9, 16, 25] Evens: [2, 4, 6, 8, 10] Sorted: [3, 17, 42, 56, 99] Sum: 217 Max: 99
Tip: List comprehension syntax: [expression vibe variable thru iterable]. Add bruh condition at the end to filter!

Lesson 7

Dictionaries — Key-Value Vibes

Dictionaries store key-value pairs. Loop through them with vibe...thru and use .items(), .keys(), .values().

dicts.rpp ▶ Try it 
# Create a dictionary
player = {"name": "xX_Slayer_Xx", "level": 42, "hp": 100}
yeet(f"Player: {player}")
yeet(f"Name: {player['name']}")

# Loop through key-value pairs
scores = {"Alice": 95, "Bob": 87, "Charlie": 92}
yeet("Scoreboard:")
vibe name, score thru scores.items():
    yeet(f"  {name}: {score}")

# Dictionary methods
yeet(f"All names: {list(scores.keys())}")
yeet(f"All scores: {list(scores.values())}")

# Add and update
scores["Diana"] = 98
yeet(f"Updated: {scores}")
Output
Player: {'name': 'xX_Slayer_Xx', 'level': 42, 'hp': 100} Name: xX_Slayer_Xx Scoreboard: Alice: 95 Bob: 87 Charlie: 92 All names: ['Alice', 'Bob', 'Charlie'] All scores: [95, 87, 92] Updated: {'Alice': 95, 'Bob': 87, 'Charlie': 92, 'Diana': 98}

Lesson 8

Blueprints — OOP Time

Object-oriented programming uses blueprint instead of class. Think of blueprints as templates for creating objects.

OOP keywords

blueprint = class (define a template)
cook __init__(self, ...): = constructor
self = reference to the current object

oop.rpp ▶ Try it 
# Define a blueprint (class)
blueprint Pet:
    cook __init__(self, name, species):
        self.name = name
        self.species = species
        self.energy = 100

    cook greet(self):
        serve f"{self.name} the {self.species} says hi!"

    cook play(self):
        self.energy -= 20
        serve f"{self.name} played! Energy: {self.energy}"

# Create objects from the blueprint
cat = Pet("Whiskers", "Cat")
dog = Pet("Rex", "Dog")

yeet(cat.greet())
yeet(dog.greet())
yeet(cat.play())
yeet(cat.play())
yeet(f"{cat.name}'s energy: {cat.energy}")
Output
Whiskers the Cat says hi! Rex the Dog says hi! Whiskers played! Energy: 80 Whiskers played! Energy: 60 Whiskers's energy: 60

Lesson 9

Error Handling — YOLO / Oof

Things go wrong. Handle it gracefully with yolo (try), oof (except), and anyway (finally).

Error handling keywords

yolo = try (attempt risky code)
oof = except (catch errors)
anyway = finally (always runs)
tantrum = raise (throw an error)
betcha = assert (verify a condition)

errors.rpp ▶ Try it 
# Safe division with yolo/oof
cook safe_divide(a, b):
    yolo:
        result = a / b
        serve f"{a} / {b} = {result}"
    oof Exception aka e:
        serve f"Oof! Can't divide: {e}"

yeet(safe_divide(10, 3))
yeet(safe_divide(10, 0))

# Custom error with tantrum
cook check_age(age):
    bruh age < 0:
        tantrum "Age can't be negative, that's sus"
    bruh age < 13:
        serve "Too young for this app"
    serve "Welcome in!"

yeet(check_age(25))
yolo:
    yeet(check_age(-5))
oof Exception aka e:
    yeet(f"Caught: {e}")
Output
10 / 3 = 3.3333333333333335 Oof! Can't divide: ZeroDivisionError: division by zero Welcome in! Caught: Age can't be negative, that's sus
Tip: Use aka (as) to give the caught exception a name so you can yeet the error message.

Lesson 10 — Final Boss

Putting It All Together

Time to combine everything you've learned into one program. Let's build a mini RPG character system!

final_boss.rpp ▶ Try it 
# Mini RPG Character System
blueprint Character:
    cook __init__(self, name, role, hp):
        self.name = name
        self.role = role
        self.hp = hp
        self.max_hp = hp
        self.inventory = []
        self.xp = 0

    cook status(self):
        serve f"[{self.role}] {self.name} | HP: {self.hp}/{self.max_hp} | XP: {self.xp}"

    cook take_damage(self, dmg):
        self.hp -= dmg
        bruh self.hp < 0:
            self.hp = 0
        serve f"{self.name} took {dmg} damage! HP: {self.hp}"

    cook heal(self, amount):
        self.hp += amount
        bruh self.hp > self.max_hp:
            self.hp = self.max_hp
        serve f"{self.name} healed! HP: {self.hp}"

    cook gain_xp(self, amount):
        self.xp += amount
        serve f"{self.name} gained {amount} XP! Total: {self.xp}"

    cook loot(self, item):
        self.inventory.append(item)
        serve f"{self.name} picked up: {item}"

# Create heroes
warrior = Character("Bruh Knight", "Warrior", 120)
mage = Character("Yeet Wizard", "Mage", 80)

yeet("=== Party Status ===")
yeet(warrior.status())
yeet(mage.status())

# Battle simulation
yeet("\n=== Battle! ===")
yeet(warrior.take_damage(30))
yeet(mage.take_damage(15))
yeet(warrior.heal(20))

# Loot phase
yeet("\n=== Loot! ===")
loot_table = ["Sword of Yeeting", "Shield of Nocap", "Potion of Grind"]
vibe i, item thru enumerate(loot_table):
    bruh i % 2 == 0:
        yeet(warrior.loot(item))
    nah:
        yeet(mage.loot(item))

# XP gain
yeet("\n=== XP Gained ===")
party = [warrior, mage]
vibe hero thru party:
    yeet(hero.gain_xp(50))

# Final status
yeet("\n=== Final Status ===")
vibe hero thru party:
    yeet(hero.status())
    yeet(f"  Inventory: {hero.inventory}")
Output

HP: 65 Bruh Knight healed!
