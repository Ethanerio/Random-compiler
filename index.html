Random++ Language Reference

About Random++

Random++ is the most unhinged programming language ever created. It has its own unique syntax that reads like internet slang. yeet to print, cook to define functions, bruh for if-statements, and yolo for try-catch. Compiled and executed entirely in your browser.

Data Types

Random++ supports the following types:

# Numbers
x = 42          # int
y = 3.14        # float
z = 0xFF        # hex literal
b = 0b1010      # binary literal

# Strings
name = "Hello"
multi = """triple
quoted string"""
greeting = f"Hi, {name}!"

# Boolean & None
flag = nocap    # that's true, no cap
empty = ghost   # it ghosted (null)
lie = cap       # cap = false

# Collections
my_list = [1, 2, 3]
my_dict = {"key": "value"}
my_set = {1, 2, 3}
my_tuple = (1, 2, 3)

Control Flow

# bruh / sus / nah (if / elif / else)
bruh x > 0:
    yeet("positive")
sus x == 0:
    yeet("zero")
nah:
    yeet("negative")

# grind (while loop)
grind condition:
    do_something()

# vibe...thru (for loop)
vibe item thru collection:
    process(item)

vibe i thru range(10):
    yeet(i)

# bail and skip (break / continue)
vibe i thru range(100):
    bruh i == 5:
        bail
    bruh i % 2 == 0:
        skip
    yeet(i)

Functions

# cook = define, serve = return
cook greet(name):
    serve f"Hello, {name}!"

# Default parameters
cook power(base, exp=2):
    serve base ** exp

# *args and **kwargs
cook flexible(*args, **kwargs):
    yeet(args)
    yeet(kwargs)

# quickmaf (lambda)
square = quickmaf x: x ** 2

# Recursion
cook factorial(n):
    bruh n <= 1:
        serve 1
    serve n * factorial(n - 1)

Blueprints (Classes)

blueprint Animal:
    cook __init__(self, name, sound):
        self.name = name
        self.sound = sound

    cook speak(self):
        serve f"{self.name}: {self.sound}!"

blueprint Dog(Animal):
    cook __init__(self, name):
        self.name = name
        self.sound = "Woof"

dog = Dog("Rex")
yeet(dog.speak())

List Comprehensions

# Basic
squares = [x**2 vibe x thru range(10)]

# With condition
evens = [x vibe x thru range(20) bruh x % 2 == 0]

# Dict comprehension
scores = {name: len(name) vibe name thru names}

# Ternary expression
result = "yes" bruh condition nah "no"

Error Handling

yolo:
    risky_operation()
oof Exception aka e:
    yeet(f"Error: {e}")
anyway:
    cleanup()

# Throw a tantrum (raise)
tantrum "Something went wrong"

# betcha (assert)
betcha x > 0, "x must be positive"

Keyword Cheat Sheet

askbro    → input          sus       → elif
cook      → def            nah       → else
serve     → return         vibe      → for
blueprint → class          thru      → in
steal     → import         grind     → while
yoink     → from           bail      → break
aka       → as             skip      → continue
yolo      → try            chill     → pass
oof       → except         toss      → del
anyway    → finally        betcha    → assert
tantrum   → raise          worldwide → global
quickmaf  → lambda         using     → with

cap       → False          unless    → or
ghost     → None           nope      → not
